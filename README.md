
# Simulated Ransomware Study in Python

> Educational project developed in a controlled environment for cybersecurity learning only.

## About the Project

This repository documents a Python-based simulation inspired by ransomware behavior. The objective is to understand the stages of a ransomware incident, including file discovery, encryption concepts, recovery, and the social-engineering component commonly represented by a ransom note.

All activities were performed only with test files in an isolated environment. This project must not be used against real files, systems, or users.

## Learning Objectives

- Understand the typical workflow of ransomware.
- Learn basic concepts of symmetric encryption and decryption.
- Recognize the impact of ransomware on data availability.
- Practice safe testing with disposable files.
- Study defensive strategies and incident-response practices.

## Project Scope

The study includes:

- Creation of sample files for testing.
- A controlled encryption/decryption demonstration.
- A simulated ransom message for awareness purposes.
- Documentation of recovery steps.
- Defensive recommendations.

## Safe Environment

Before running any experiment, the following precautions were adopted:

- Only disposable test files were used.
- Tests were performed in an isolated folder or virtual machine.
- No personal, academic, business, or system files were included.
- Backups were created before testing.
- The simulation was never deployed or shared as a real ransomware tool.

## Ransomware Lifecycle Studied

1. **File identification** — identifying target files in a controlled test directory.
2. **Encryption concept** — understanding how encryption affects file availability.
3. **Ransom note simulation** — analyzing the psychological pressure used in extortion attacks.
4. **Recovery** — restoring access through controlled decryption or backups.
5. **Defense** — applying security controls to reduce the chance and impact of attacks.

## Defense and Prevention

Recommended measures against ransomware include:

- Maintain frequent, offline, and tested backups.
- Keep operating systems and applications updated.
- Use antivirus or endpoint protection solutions.
- Restrict unnecessary administrator privileges.
- Be cautious with unknown attachments, links, and downloads.
- Segment networks to limit lateral movement.
- Use multi-factor authentication.
- Train users to identify phishing and social-engineering attempts.
- Prepare and test an incident-response plan.

## Ethical Notice

This repository is exclusively for educational and defensive cybersecurity purposes. The author does not encourage unauthorized access, data destruction, extortion, or disruption of systems.
